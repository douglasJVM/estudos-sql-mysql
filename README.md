# 🗄️ Estudos de SQL & MySQL

Repositório criado para documentar e praticar os conceitos fundamentais de Banco de Dados Relacionais e a linguagem SQL (Structured Query Language).

## 🚀 Conteúdo do Script (`script.sql`)

O script contido neste repositório cobre todo o ciclo de vida básico de manipulação de dados em uma tabela (**CRUD**):

* **DDL (Data Definition Language):**
  * `CREATE TABLE`: Criação da tabela `funcionarios` com tipos de dados (`INT`, `VARCHAR`, `DECIMAL`), chave primária autoincrementada (`PRIMARY KEY AUTO_INCREMENT`) e restrições de obrigatoriedade (`NOT NULL`).

* **DML (Data Manipulation Language) - CRUD:**
  * **Create (`INSERT INTO`):** Inserção de novos registros na tabela.
  * **Read (`SELECT`):** Consulta e projeção de dados específicos e filtrados.
  * **Update (`UPDATE`):** Atualização de dados existentes usando a cláusula `WHERE` para precisão.
  * **Delete (`DELETE`):** Remoção de registros específicos utilizando filtros seguros.

## 🛠️ Tecnologias Utilizadas
* **MySQL / SQL ANSI**
